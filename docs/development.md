# Development

## Build

Requirements:

- Rust via rustup. `rust-toolchain.toml` pins the version and the `wasm32-unknown-unknown` target;
  rustup installs them on first build.
- `wasm-bindgen-cli` matching the `wasm-bindgen` crate version in `Cargo.lock`.
- Node.js.

```sh
cargo install wasm-bindgen-cli --version 0.2.128 --locked
npm install
npm run build        # -> dist/index.html (single self-contained file)
npm run dev          # dev server with the same app
```

If Homebrew's `rustc` shadows rustup's, put `~/.cargo/bin` first in `PATH`.

## Test

```sh
cargo test                                                                # unit tests, plus decoding the committed test drawing
cargo test --release -p raster --test samples -- --ignored --nocapture    # decode everything in ./samples
```

CI runs `cargo test`, then `npm run build`. Pushing to `main` deploys the build to
[GitHub Pages](https://sinderc.github.io/DWG-Viewer/).

### Test files

Put test files in `./samples/` (git-ignored). These examples generate synthetic ones:

```sh
cargo run --release --example make_sample -- samples/test.cal 18000 12700 090,270   # CALS raster
cargo run --release --example dxf_to_dwg -- samples/in.dxf samples/out.dwg AC1018    # DWG from a DXF (acadrust)
cargo run --release --example make_dwf -- samples                                   # DWF (classic, 6.0) and DWFx
cargo run --release --example make_cgm -- samples                                   # binary CGM
cargo run --release --example extend_baseline -- samples/in.dwg samples/out.dwg      # copy of a DXF/DWG plus a grid of extra entity types
cargo run --release --example make_baseline -- crates/raster/tests/fixtures         # the committed test drawing (DXF + DWG) that cargo test decodes
```

## Layout

- `crates/raster` — Rust/WASM decoding and rendering:
  - CALS parsing, G4 decoding (`fax` crate), TIFF decoding (`tiff` crate), orientation
  - viewport rendering: 1-bit coverage (`render.rs`), colour mip pyramid (`rgba.rs`)
  - `dxf/` — DXF parsing and block expansion into paths, exact arcs and text
  - `dwg.rs` — DWG entities mapped onto the same output via `acadrust`
  - `hpgl/` — HP-GL/2 interpreter plus PJL/PCL/RTL unwrapping
  - `dwf/` — DWF W2D interpreter, ZIP/package reading and DWFx (XPS) pages
  - `cgm/` — binary CGM interpreter; clear text is transcoded to binary first
- `web/src/formats` — format plugin interface (`types.ts`), shared WASM adapter (`wasm.ts`) and one
  plugin per format; `dxf.ts` draws all vector geometry with Canvas 2D
- `web/src/viewer.ts` — canvas view, zoom and pan
- `web/src/main.ts` — UI wiring, toolbar, measuring and keyboard shortcuts
- `web/pkg/` — generated by `npm run build:wasm`; do not edit

Vector formats are parsed in Rust and returned as paths and text; TypeScript only strokes them.
New formats are `FormatPlugin`s registered in `web/src/main.ts`.
